# IELTS Writing Bot — Landing Page

Instagram va tashqi tarmoqlardan keluvchi foydalanuvchilar uchun moslashtirilgan, tezkor, mobil-do'st va zamonaviy taqdimot sahifasi.

## Texnologiyalar
- **Frontend kutubxonasi**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS (Dark/Indigo mavzusi)
- **Ikonkalar**: Lucide React

## Bo'limlar (SPEC.md talablari asosida)
1. **Hero**: Bot nomi, shior, Telegram bot havolasi, interaktiv jonli Telegram chat namoyishi
2. **Qanday ishlaydi**: 3 qadam (Insho yuborish → AI tahlil → Natija va tavsiya)
3. **Afzalliklar**: Tezkor natija (30 soniya), 24/7 mavjudlik, IELTS rasmiy mezonlari, Streak va doimiy o'sish
4. **CTA**: Yakuniy harakatga chaqiruvchi blok va Telegram botga o'tish tugmasi

## Ishga tushirish
```bash
cd landing_page
npm install
npm run dev
```
Brauzerda: `http://localhost:3001`
